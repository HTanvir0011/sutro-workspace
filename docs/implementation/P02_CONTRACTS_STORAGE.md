- The shared save promise drains edits made while a transaction is pending. Navigation waits for the latest draft, and revisions advance only on committed saves. Failed saves retain a dirty, exportable draft and support retry.
- Blocked IndexedDB upgrades release the rejected cached connection attempt; retry succeeds after the older connection closes. Clearing cases, scans and migration metadata uses one transaction; abort preserves them and the legacy original.
- An interrupted legacy migration retains its original, resumes, and preserves already-saved revisions. Imported exports receive a fresh case ID and no imported review authority.
- Scans remain session-only by default. Explicit retention survives reload; opting out keeps the current session preview. Failed storage changes preserve the prior choice. Document removal clears its stored/session scan, attachment metadata and review entries; empty editors invalidate pending preview renders and release object URLs.
- An isolated OCR UI fixture verifies stale case/crop rejection, explicit approval, reset after candidate edits, and original/corrected text with the captured crop. This is control-flow evidence, not measured OCR accuracy or model release acceptance.
